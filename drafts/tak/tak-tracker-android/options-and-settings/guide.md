# Options & Settings

META: slides

The Settings window controls how you appear on the network and how TAK Tracker behaves. Open it any time to change your callsign, enrollment or display.

## Open Settings

![TAK Tracker Connection Settings window](./01-screenshot.png)

Tap **Settings** to open the Connection Settings window. From here you can:

- Change your **callsign**, **team color** or **role**
- Enroll with a **username and password**, or import an **SSL certificate**
- Turn on **Service on Boot** so TAK Tracker runs whenever the device starts

## Tidy up the display

Two options control how much of the main window you see:

- **Hide Quit Button** — removes the Quit button; re-show it from **Settings** by unchecking the box
- **Limited View Mode** — shows only the connection box; uncheck it in **Settings** to show all boxes again

## Lock settings and import certificates

- Tap **Lock** on the toolbar to set a password that protects your settings
- Tap **Import** on the toolbar to enroll by importing an SSL certificate `.zip` file

If TAK Tracker has not been granted access to the Android file system, a prompt opens here to allow it.
