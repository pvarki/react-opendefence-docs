# Record events

META: slides

TAK Replay records map events and chats in real time so you can replay them
later. Open the plug-ins tab on the WinTAK toolbar to begin.

## Start recording

![TAK Replay panel with Record, Stop and Recordings](./01-screenshot.png)

Select **Record** to capture all map events and chats, or open the main **TAK
Replay** panel (via **Recordings**) for more control. A recording can be paused,
resumed or stopped from the toolbar.

## Choose a recording region

![Select Region panel with map-view, shape and polygon options](./02-screenshot.png)

When you select **Record**, choose what area to capture: **Select Map View**
(only what's in view, with the zoom level preserved), **Select Existing Shape**,
**Select Polygon Region**, or **Select Rectangular Region**. Use **Reset Region
Selection** to pick a different region type.

## Record events & chats

![Recording tally over a map region](./03-screenshot.png)

Select **Start Recording**, keep or change the title, and select **OK**. A tally
shows the elapsed time and counts of events, map items and chat messages,
updating until you stop. Toggle which items are recorded via Overlay Manager.
Select **Stop Recording** to finish — the Timeline Viewer opens automatically.
