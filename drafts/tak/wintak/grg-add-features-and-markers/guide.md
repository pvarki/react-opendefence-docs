# Add features & markers

META: slides

Beyond the grid itself, a GRG can carry map references and markers. Open
**Edit GRG > Edit GRG Components** and expand each item to add it.

## Add a crosshair

![Crosshair panel with Move Crosshair, color and size](./01-screenshot.png)

**Crosshair** places an aiming cross on the grid. Reposition it with **Move
Crosshair**, set its color and opacity, and adjust the size. Toggle it with the
**Show Crosshair** checkbox.

## Add an info box

![InfoBox panel — Title, Location, Date, Classification](./02-screenshot.png)

**InfoBox** shows a labelled box on the grid. Edit the **Title**, **Location**,
**Date** and **Classification** text and their colors; set the Theme, Style,
Placement and Text Alignment. Toggle it with the **Show Info Box** checkbox.

## Add a scale bar

![ScaleBar panel — cell range or map range](./03-screenshot.png)

**ScaleBar** adds a scale showing either cell range or map range. The cell-range
value defaults to the Edit Grid spacing; adjust the map-range size and segment
values to taste. Toggle it with the **Show Scale Bar** checkbox.

## Add a compass

![Compass panel — Full or True + Mag style](./04-screenshot.png)

**Compass** adds a north reference. Pick the style (**Full** or **True + Mag**),
its position and declination; with True + Mag you can also set the color. Toggle
it with the **Show Compass** checkbox.

## Add markers with Point Dropper

![Point Dropper panel with marker types and Recently Added](./05-screenshot.png)

Select **Open Point Dropper** to place markers on the grid — choose a marker type
and tap a position; use the arrows for more types. Placed markers appear under
**Recently Added**, where they can be sent, edited or deleted. Use **Edit Grid
Markers > Name Markers** to auto-rename spot markers by the quadrant they fall in.

## Import points from a file

![Assign Columns window for matching CSV columns](./06-screenshot.png)

Import markers from a **.csv** or **.xlsx** with **Import Points**. Name, Prefix
and Location (Lat/Long or MGRS) columns are required; Elevation, Remarks, Color
and Type are optional. If a column doesn't match, the **Assign Columns** window
lets you map each column — or change a marker's type — before importing.
