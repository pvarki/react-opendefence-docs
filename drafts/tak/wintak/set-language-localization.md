# Set language & localization for WinTAK

META: slides

WinTAK requires Windows to be set to **English** with the **United States** region — do this _before_ you install the app. Work in pairs if you can: one reads, one drives.

## Search for Time and Language

![Time and Language search](_assets/Kuva1.png)

Open the Windows settings: type **Time and Language** into the search bar (bottom-left).

## Open Region settings

![Region in the sidebar](_assets/Kuva2.png)

First change the region. In **Time and Language**, select **Region** from the sidebar.

## Set region to United States

![Region set to United States](_assets/Kuva3.png)

Set the country or region to **United States**. Make sure the regional format is also **English (United States)**.

## Set the display language to English (US)

![Language settings](_assets/Kuva4.png)

Back in the sidebar, select **Language**. Set the Windows display language to **English (United States)**.

## Sign out and back in

![Sign out to apply the language](_assets/Kuva5.png)

Finalize the display-language change by signing out and signing back in.

## Language set

![Display language complete](_assets/Kuva8.png)

If English is now your display language, the localization is complete. If English was **not** available to choose, the next two steps add it — otherwise you're ready to install WinTAK.

## If English is missing: add a language pack

![Install language pack](_assets/Kuva6.png)

If English isn't in the display-language list, press **Add a language**, search for English, and press **Install language pack**. Wait for it to install.

## Select English, then sign out and in

![Select English as display language](_assets/Kuva7.png)

Once installed, select English as the display language as above, then sign out and back in. Windows is now localized — next, download and install WinTAK.
