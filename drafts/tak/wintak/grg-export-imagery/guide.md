# Export & share a GRG

META: slides

When the GRG is ready, export it as a file or send it straight to your team.

## Export the GRG

![GRG Builder panel with the Export icon highlighted](./01-screenshot.png)

Select the **Export** icon and choose **Export as KMZ** or **Export as JSON**.
The file is saved to **Documents > WinTAK > Export** by default.

## Send a GRG & set preferences

If you exported as JSON, select **Send GRG** on the GRG Builder panel to send it
to contacts. To clear everything placed this session, use **Delete** at the top
of the panel. Configure **Auto Import GRG**, the JSON directory and **Set GRG
Spacing Intervals** under **Edit GRG > Edit GRG Components > Open Preferences**.
