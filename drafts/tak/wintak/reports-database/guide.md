# Browse the reports database

META: slides

Reports stored on the TAK Server can be searched, filtered and visualized.

## Filter & sort reports

![Reports filter panel with type, status and importance options](./01-screenshot.png)

Select the **Filter** icon to limit the list by current map view, date range,
report type, status, importance or user callsign; **Clear Filters** shows
everything again. Select **Sort** to order the list by Date, User Callsign,
Importance, Status, Title or Type — click a choice again to reverse it.

## Build a reports dashboard

![Reports Dashboard with pie and bar charts](./02-screenshot.png)

Open **Dashboard** from the toolbar and filter down to the reports you want.
Select **Create New Chart**, choose how to group it (Importance, Scale, Status,
Type or User Callsign) and a pie or bar chart, then **Create**. Multiple charts
can run side by side, each with its own filters.
