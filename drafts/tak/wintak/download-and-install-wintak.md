# Download & install WinTAK

META: slides

Everything you need to set up WinTAK comes from Deploy App's **TAK** page — the WinTAK installer and your personal Client Package. Download both, then run the installer.

## Open Deploy App's TAK page

Open Deploy App and go to the **TAK** page. It gives WinTAK users two downloads: the WinTAK application and your Client Package.

## Download WinTAK

Download the WinTAK application from the **Defence Forces' designated location** — the link is on the TAK page.

Important: only download Windows applications from the instructed location.

## Download your Client Package

Press the green **Download your Client Package** button (also on the front page) and save the `.zip` file. You will point WinTAK at this package after installing.

## Extract the package and find the installer

![Locate the .msi in the Products folder](_assets/Kuva9.png)

Find the downloaded WinTAK `.zip`, extract it, and locate the `.msi` installer inside the zip's **Products** folder. Double-click the `.msi` to open the installer.

## Run the Setup Wizard

![Setup Wizard — choose folder](_assets/Kuva10.png)

Install WinTAK with the Setup Wizard. Press **Next**, then choose the installation folder.

## Choose the install folder

![Browse for install folder](_assets/Kuva11.png)

Optionally change the folder with **Browse**, then press **Next**.

## Select components — include Data Sync

![Select components](_assets/Kuva12.png)

Select the components to install. Select **at least**:

- **Data Sync**

## Install

![Ready to install](_assets/Kuva13.png)

Press **Next**. When the Wizard is ready, press **Install**.

## Finish

![Finish the installer](_assets/Kuva13-1.png)

Press **Next** to finish. WinTAK is now installed — next, open it and import your Client Package.
