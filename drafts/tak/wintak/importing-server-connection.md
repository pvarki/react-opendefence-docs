# Importing Server Connection

META: slides

With WinTAK installed, open it for the first time and connect it to your unit's TAK server by importing the Client Package you downloaded.

## Open WinTAK

![Open WinTAK from the desktop](_assets/Kuva14.png)

Open the **WinTAK** application from the desktop.

## Accept the EULA

![Device Setup Wizard — EULA](_assets/Kuva16.png)

After a moment the **Device Setup Wizard** opens. Its first step is to accept the **EULA**.

## Import your Client Package

![Import the data package](_assets/Kuva17.png)

The wizard asks whether to import a data package — this is your **Client Package** (`Name.zip`) downloaded from this app's front page. Select **Yes** and point to the Client Package in your downloads.

## Choose an import strategy

![Select Import Strategy window](_assets/Kuva18.png)

After you choose the package and press **Open**, the **Select Import Strategy** window opens.

## Select UserPreferenceImportStrategy

![UserPreferenceImportStrategy](_assets/Kuva19.png)

Select **UserPreferenceImportStrategy** and press **OK**.

## Choose a map base

![Choose a map base](_assets/Kuva20.png)

The package may include several **map bases**. Choose your preferred one — you can change it later.

## Set your callsign

![Enter your callsign](_assets/Kuva21.png)

The wizard asks whether to define your callsign. Select **Yes** and enter your **assigned callsign**. It then asks for additional WMS (map) service sources.

## Skip extra WMS sources

![Clear the WMS boxes](_assets/Kuva23.png)

Extra WMS sources are not needed — clear the boxes and press **OK**.
