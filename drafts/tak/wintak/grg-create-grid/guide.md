# Create & edit a GRG

META: slides

GRG Builder makes a GRG (Gridded Reference Graphic — a KMZ) from a snapshot of
high-resolution map imagery. The grid can also carry map items, a scale,
compass, crosshair and an MGRS grid.

## Create a GRG

![GRG Builder panel with the Add GRG button](./01-screenshot.png)

Pick a map source from **Maps & Favorites** and pan/zoom to your area of
interest. Select the **GRG Builder** icon on the Creation tab, then **Add GRG
(+)** to drop a grid on the map. Select **Add GRG** again to place more. To
rename a grid, select **Edit GRG** (pencil) > **Change GRG Name** > **Rename**.

## Edit the grid

![Edit Grid panel — Move Grid, Height x Width, Spacing and Color](./02-screenshot.png)

Select **Edit GRG** > **Edit GRG Components** > **Edit Grid**. **Move Grid**
recenters it; change **Height x Width** and **Spacing** to resize the cells (or
**Add Size** for a custom layout), and set the grid **Color** and opacity with
the slider. To reshape the footprint, use **Redefine GRG**: right-click a corner,
left-click a new point, then **Done Editing** to save.

## Label the grid

![Grid Label panel with Alphanumeric / MGRS / Both styles](./03-screenshot.png)

Open **Grid Label** to letter and number the grid. Choose **Alphanumeric**,
**MGRS** or **Both**; for MGRS, set the orientation, colors and **Precision**.
Toggle labels with the **Show Grid Labels** checkbox.
