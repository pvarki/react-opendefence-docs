# Make sure you have the App

META: slides

WinTAK is a Windows desktop client you install manually from a client package — unlike ATAK there is no app store. Work in pairs if you can: one reads, one drives. First we set Windows to English (US), then download and install WinTAK.

## Search for Time and Language

![Time and Language search](_assets/Kuva1.png)

WinTAK requires the workstation language to be **English** and the region **United States**. Before installing, open the Windows settings: type **Time and Language** into the search bar (bottom-left).

## Open Region settings

![Region in the sidebar](_assets/Kuva2.png)

First change the region. In **Time and Language**, select **Region** from the sidebar.

## Set region to United States

![Region set to United States](_assets/Kuva3.png)

Set the country or region to **United States**. Make sure the regional format is also **English (United States)**.

## Set the display language to English (US)

![Language settings](_assets/Kuva4.png)

Back in the sidebar, select **Language**. Set the Windows display language to **English (United States)**.

## Sign out and back in

![Sign out to apply the language](_assets/Kuva5.png)

Finalize the display-language change by signing out and signing back in.

## Language set

![Display language complete](_assets/Kuva8.png)

If English is now your display language, the language settings are complete. If English was **not** available to choose, the next two steps add it — otherwise skip ahead to downloading WinTAK.

## If English is missing: add a language pack

![Install language pack](_assets/Kuva6.png)

If English isn't in the display-language list, press **Add a language**, search for English, and press **Install language pack**. Wait for it to install.

## Select English, then sign out and in

![Select English as display language](_assets/Kuva7.png)

Once installed, select English as the display language as above, then sign out and back in. The language settings are now complete — next we install WinTAK.

## Download WinTAK

Download the WinTAK application from the **Defence Forces' designated location** — the link is on this Deploy App's TAK page.

Important: only download Windows applications from the instructed location.

## Download your Client Package

On the Deploy App TAK page, press the green **Download your Client Package** button (it is also on the front page), and save the `.zip` file. You will point WinTAK at this package later.

## Extract the package and find the installer

![Locate the .msi in the Products folder](_assets/Kuva9.png)

Find the downloaded WinTAK `.zip`, extract it, and locate the `.msi` installer inside the zip's **Products** folder. Double-click the `.msi` to open the installer.

## Run the Setup Wizard

![Setup Wizard — choose folder](_assets/Kuva10.png)

Install WinTAK with the Setup Wizard. Press **Next**, then choose the installation folder.

## Choose the install folder

![Browse for install folder](_assets/Kuva11.png)

Optionally change the folder with **Browse**, then press **Next**.

## Select components — include Data Sync

![Select components](_assets/Kuva12.png)

Select the components to install. Select **at least**:

- **Data Sync**

## Install

![Ready to install](_assets/Kuva13.png)

Press **Next**. When the Wizard is ready, press **Install**.

## Finish

![Finish the installer](_assets/Kuva13-1.png)

Press **Next** to finish. WinTAK is now installed — next we open it and connect to the server.
