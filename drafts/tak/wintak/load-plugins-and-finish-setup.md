# Load Plugins & Finish Setup

META: slides

Finish the Device Setup Wizard by enabling the Data Sync plugin and elevation data, then review your preferences and set the measurement units.

## Install the Data Sync plugin

![Select the DataSync plugin](_assets/Kuva24.png)

The application asks whether to install plugins. Select **DataSync** and press **OK**.

## Download elevation data (DTED-0)

![Download DTED-0 elevation data](_assets/Kuva25.png)

WinTAK then asks whether to download DTED-0 elevation models automatically. Select **Yes**.

## Review My Preferences

![My Preferences](_assets/Kuva26.png)

The basic setup is done — check **My Preferences**. Your **Callsign**, team colour (**My Team**) and role (**My Role**) should match what you were assigned, and **My Display Type** should be **Ground**.

If you are a command post user, your role should be **HQ**.

## Check the TAK Network Status

![TAK Network Status](_assets/Kuva27.png)

Check the **TAK Network Status**: a green cloud means the server connection is OK, red means disconnected. If it stays red, check your internet connection and restart WinTAK (see Troubleshooting).

## Open unit settings

![Hamburger menu → Settings](_assets/Kuva28.png)

Now set the measurement units. Press the **hamburger menu** (three stacked lines) in the top-left corner, then select **Settings**.

## Open Display Preferences

![Display Preferences → Unit Display Format Preferences](_assets/Kuva29.png)

Select **Display Preferences**, then open **Unit Display Format Preferences**.

## Set the unit format

![Unit Display Format Preferences](_assets/Kuva30.png)

Check that the unit settings match the picture, and change them if necessary.

## WinTAK is set up

![Setup complete](_assets/Kuva31.png)

WinTAK is now set up. The usage guide following the standard model is under **Usage by Role** — and on this Deploy App's front-page menu under **Usage**.
