# Create a report

META: slides

The Reports plugin lets you create, place, edit and upload field reports of many
types, using preconfigured or custom templates. After a report is created, an
icon marks the spot on the map where it was taken.

## Open the Reports tool

![Reports window listing downloaded and local reports](./01-screenshot.png)

Select **Reports** from the toolbar. The window lists reports downloaded from the
TAK Server plus any local reports on the device. A server connection isn't needed
to create a report, but it is required to download, upload, or search for reports
written by other users.

## Choose a report template

![Select Report Category list of templates](./02-screenshot.png)

Select **+** to open the list of report templates and choose one to start. Each
template has predefined fields; any field marked **Required** must be filled
before the report can be uploaded. You can close and save a report locally
without filling every field.

## Fill in the report

![Report Details panel with title, importance and fields](./03-screenshot.png)

Complete the report fields — Title, Importance, descriptions, and so on. The
local device's Self-Marker is the default location. Select **Pan-To** to bring
the location field into view, and **Edit** to change the location.

## Set the report location

![Location options menu](./04-screenshot.png)

Set the location with one of: **Use my current location**, **Based on map click**,
**Enter coordinates** (MGRS, Deg, DM, DMS, UTM or Address), **Use current map
view**, **Define location boundary** (draw a polygon), or **Define route**.
