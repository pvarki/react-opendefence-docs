# Custom report templates

META: slides

Preconfigured report templates can be edited, and you can build your own from
scratch.

## Start a custom template

![Select Report Category with the Custom category](./01-screenshot.png)

To edit a default template, choose the report type and select **Edit** next to
it — it opens in the editor to save as a new custom template. To build a new one,
select **+** next to the **Custom** category; this creates an empty template with
one section and a text field.

## Name it and add sections

![Template Editor showing Template Type and a section](./02-screenshot.png)

Enter a name in the **Template Type** field (this becomes the stored template
name). Use the editor to add sections and fields, delete a section or field, mark
a section **Required**, or **Clear** the template.

## Add field types

![Template Editor element type menu](./03-screenshot.png)

Select **+** within a section to add a field: Options, Multi-Select Options,
Section, Checkbox, Date, Location, Number with Units, Number, Range, Route, Text
or Time.

## Save the template

![Template Editor with the live preview pane](./04-screenshot.png)

Drag the window out to see a live preview on the right as you build. Select
**Save** to store it under Custom using its title, **Save As** to give it a new
name, or **Save / Fill Out** to store it and immediately start a report from it.

## Reports preferences

![Report preferences fields — importance, scale, descriptions](./05-screenshot.png)

Tailor the report layout under **Settings > Tool Preferences > Reporting
Preferences**: **Allow sending to TAK users over Data Package**, send Data
Packages to all contacts automatically, and show or hide the Importance, Scale,
Scale Description and User Description fields.
