# Manage Contacts

META: slides

Find who you can reach, how to reach them, and pull up a callsign's details without leaving the map.

## Open the Contacts list

![ATAK Contacts list showing callsigns with comms icons](./01-screenshot.png)

Open the Contacts tool to see everyone on the network. The last column shows each callsign's default communication type. Use **Unread Only** and **Show All** at the bottom to limit the list.

## Filter by communication type

![Communication type dropdown listing Data Package, GeoChat, Email, Phone, SMS, VoIP, XMPP](./02-screenshot.png)

Tap the arrow next to **Contacts** at the top of the list. Pick a type — **Data Package**, **GeoChat**, **Email**, **Phone**, **SMS**, **VoIP** or **XMPP** — to show only callsigns reachable that way.

## Filter and favourite callsigns

![Filter Contacts window with check boxes, Select All and Hide Filtered Contacts](./03-screenshot.png)

Use multi-select to tick callsigns and remove them from the list and map; enable **Hide Filtered Contacts** to keep them off. To favourite a contact, tap the **Star** icon, tap the **+** icon, choose the contact(s), then tap **Add**.

## Sort and search

![Contacts list with sort and search icons at the top right](./04-screenshot.png)

Tap the **Sort** icon to reorder the list — alphabetically, by connection status, by unread messages or by distance from you. Each tap changes the sort. Tap the **Search** icon and type to jump to a specific callsign.

## Open a contact profile card

![MARVIN profile card showing role, node type and default connector](./05-screenshot.png)

Tap the second-to-last column for any callsign to open its profile card. It shows role, software version, node type, default connector, last report time, battery, location and the comms types available for that contact.
