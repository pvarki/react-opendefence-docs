# Create a Report

META: slides

Build and send a structured report from ATAK so your HQ gets the picture in a known format, saved locally or pushed straight to the TAK Server.

## Open the Reports tool

![Reports panel toolbar showing Create A Report and Editor buttons](./01-screenshot.png)

Tap **Reports** in the toolbar. The Reports panel opens with **Search**, **Multi-select**, **Sort**, **Create A Report**, **Editor**, **Visibility** and **Delete All**. You do not need a TAK Server connection to create one.

## Start a new report

![Report Category prompt listing Counter Intel, DHS, Surveillance and Custom](./02-screenshot.png)

Tap **Create A Report**. The **Report Category** prompt appears. Pick the report type that fits, for example **Counter Intel**, **DHS**, **Surveillance** or **Custom**.

## Fill in the fields

![Report editor with Title, DateTime, Location and Tags fields](./03-screenshot.png)

Work down the form and complete each field. Required fields show in **red text** until filled. Add a **Title**, check the **DateTime**, and use **Tags** to make the report easy to find later.

## Set the location

![Location row with the pencil edit icon and a grid reference](./04-screenshot.png)

Use the **pencil** icon on the **Location** row to set or edit the report position, then add a **Location Description** if it helps. The grid reference is filled in automatically.

## Add attachments

![Attachments section with Add New Attachment and one attached photo](./05-screenshot.png)

Tap **+ Add New Attachment** to attach a photo, video or file from the device. Tap the **Delete** icon next to any item to remove it.

## Save, upload or send

![Send dialog with Contact, Select Server, Cloud/FTP, Choose App and Export options](./06-screenshot.png)

When finished, tap **Save & Close** to keep a local copy, or **Upload** to publish to the **TAK Server**. The Send dialog can also push the report to a **Contact**, **Cloud/FTP**, another app, or **Export** it.
