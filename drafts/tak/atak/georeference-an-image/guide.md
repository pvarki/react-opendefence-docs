# Georeference an Image (Rubber Sheet)

META: slides

Pin a flat map or sketch onto the live terrain, then stretch and rotate it to line up with the ground so the whole team reads the same picture.

## Open the Rubber Sheet tool

![Radial menu of Rubber Sheet controls over a 2D image laid on the map](./01-screenshot.png)

Select the **Rubber Sheet** icon to open its toolbar. The toolbar options are **Import**, **Sort**, **Export** and **Search**.

## Import the 2D image

![Imported image overlay shown on the map view with its edit radial menu](./02-screenshot.png)

Pan and zoom the map to where the imagery belongs. Select the **+** icon, pick the image file, then select **OK**. The image lands on the map and is listed under **Rubber Sheets** in **Overlay Manager**.

## Open the radial menu

![Radial menu around the overlay showing Edit, Rotate, Fine Adjust and Opacity](./03-screenshot.png)

Tap the imported image to open its radial menu. From here you can adjust the fit, set **Opacity**, add a **Label**, or open **Details**.

## Fit it to the ground

![Edit controls on the overlay: drag corners, edges and center to fit the terrain](./04-screenshot.png)

Select **Edit** to size, rotate and place the image.

- Drag a corner to resize.
- Drag an edge midpoint to change size and rotation.
- Drag the center to move the whole image.

Select **Rotate** to spin it with two fingers without changing size. When it lines up, select **End Editing**.

## Export as KMZ

![Overlay radial menu with the Details option used to export the rubber sheet](./05-screenshot.png)

Select **Export** from the rubber sheet **Details**, or from the **Rubber Sheet** category in **Overlay Manager**, to save it as a KMZ file in the atak/tools/rubbersheet folder. A prompt then offers to re-import it as an image overlay.
