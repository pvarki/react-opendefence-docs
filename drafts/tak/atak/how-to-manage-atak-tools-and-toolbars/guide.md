# How to manage ATAK Tools and Toolbars

META: slides

Set up your ATAK toolbar so the tools you actually use are one tap away, and swap layouts fast in the field.

## Open the extra tools

![ATAK main toolbar with the Additional Tools button on the left](./01-screenshot.png)

Tap the **Additional Tools** button beside the toolbar to reach the tools that are not on the bar. They open in a grid by default.

## Switch to list view

![Tools panel showing tools in a vertical list with names](./02-screenshot.png)

In the Tools panel, tap **List View** to see each tool with its name in a vertical list. Easier to read when you are learning the icons.

## Switch back to grid view

![Tools panel showing tools as a grid of icons](./03-screenshot.png)

Tap **Grid View** to pack the tools back into a compact icon grid. Use whichever layout you find faster.

## Edit the toolbar

![Toolbar in Edit Mode with an Add Tool / Remove Tool hint and the New Toolbar panel](./04-screenshot.png)

Tap **Edit Toolbar** to enter Edit Mode. The default toolbar cannot be changed, so a copy is made for you. For a clean start instead, use **Add Toolbar** in the toolbars list.

## Add or remove a tool

![Edit Mode close-up showing the tool grid and drag instructions](./05-screenshot.png)

In Edit Mode you can:

- Long-press and drag a tool onto the bar to **add** it.
- Drag a tool onto an occupied slot to **replace** it.
- Long-press and rename a tool by its label.

## Delete a tool and save

![Edit Mode delete area with a trashcan icon for removing a tool](./06-screenshot.png)

Drag a tool to the trashcan to **delete** it from the bar and send it back to the tool list. When done, tap **Save** and the toolbar joins your available list.

## Manage and select toolbars

![Toolbar Manager panel listing Default, New Toolbar and Primary Toolbar with radio toggles and edit and delete icons](./07-screenshot.png)

Tap **Toolbar Manager** to see all your toolbars. Use the radio toggle to pick the **active** toolbar, **Edit** or **Delete** any line, and use **Export Toolbar** / **Import Toolbar** to share a layout with another TAK user.
