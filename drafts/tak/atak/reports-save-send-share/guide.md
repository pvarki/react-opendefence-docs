# Save, Send & Share a Report

META: slides

Once a report is filled in, this is how you keep a copy, push it to the server, and get it to the people who need it.

## Save a local copy or upload

![Report editor with Save and Close, upload and send buttons along the bottom](./01-screenshot.png)

At the bottom of the report, select **Save & Close** to keep a local copy, or the upload icon to **Upload** to the TAK Server. If several servers are configured you pick one; after upload the button greys out until you change something.

## Add or remove attachments

![Attachments panel showing Add New Attachment and a trash icon next to a photo](./02-screenshot.png)

Select **Add New Attachment** to add a photo, video, or file to the report. Select the **Delete** trash icon next to a file to drop it.

## Send the report

![Send menu with Contact, Select Server, Cloud/FTP, Choose App and Export options](./03-screenshot.png)

Select the upload or send icon to choose how the report goes out: to a **Contact**, **Select Server**, **Cloud/FTP**, **Choose App**, or **Export**. Data Sync and Cloud/FTP only show up if those plug-ins are installed.

## Send via TAK Chat or copy the text

![Send menu offering Email, TAK Chat and Copy](./04-screenshot.png)

Select the **Send** button for sending options. **TAK Chat** pushes the report to users on the network; **Copy** puts it on the clipboard to paste into any chat. For Data Sync, pick **Data Sync Upload**, choose a feed, then **Send**.

## Manage your saved reports

![Local reports list with a row of action icons under each report](./05-screenshot.png)

Saved copies live in the Reports panel. Each report has its own row of icons: **Upload**, **Details**, **PDF**, **Copy to Clipboard**, **Share**, **Visibility**, and **Delete**.

## Make a PDF or copy the text

![The same report action bar, highlighting the PDF and Copy to Clipboard icons](./06-screenshot.png)

Select **PDF** to generate a PDF of the report. Select **Copy to Clipboard** to drop the report as plain text into any Free Text or Contacts channel.

## Share via apps or delete

![The same report action bar, highlighting the Share and Delete icons](./07-screenshot.png)

Select **Share** to hand the report to any installed app that can send it. Select **Delete** to remove the report from the device. **Visibility** toggles the report marker on the map.
