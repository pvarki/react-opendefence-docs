# Go To Coordinates

META: slides

Jump the map straight to a grid reference, lat-lon, or street address - and drop a marker there if you want.

## Open Go To and pick a format

![The GoTo window with MGRS, DD, DM, DMS, UTM and ADDR format tabs across the top](./01-screenshot.png)

Select the **Go To** icon. Pick your format tab: **MGRS** (grid), **DD** / **DM** / **DMS** (lat-lon), **UTM**, or **ADDR** (address).

## Enter the coordinates

![Coordinate entry tabs showing Zone, Square, Easting and Northing fields](./02-screenshot.png)

Type the location into the fields. Tap **Cycle** to combine Easting/Northing into one field, then the whole coordinate into one large field for fast entry.

## Set the elevation

![The GoTo window showing the Elevation field and the Pull Elevation button](./03-screenshot.png)

Enter elevation in the space provided, or tap **Pull Elevation** to fill it from the map's elevation source if one is loaded.

## Jump to an address

![Address bar reading Type in the address with a Find button and a Set the address as the title checkbox](./04-screenshot.png)

On the **ADDR** tab, type the address and tap **Find**. It drops a marker or pans the map there. Tick **Set the address as the title** to use the address as the marker label.
