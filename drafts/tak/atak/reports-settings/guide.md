# Configure Report Settings

META: slides

Set up Reports once so every report you send uses the right defaults without extra taps in the field. Open **Settings > Tool Preferences > Specific Tool Preferences > Reporting Preferences**.

## Set how reports are sent

![Reports General Settings panel with send and auto options](./01-screenshot.png)

In **General Settings**, turn on **Allow sending to ATAK users over Data Package** to be prompted for a send method, and **Send Report Data Package To All Contacts Automatically** to push to everyone on the network. Use **Always Show Queried Reports** to keep server results on screen.

## Default your report location to self

![General Settings with Set report location to self marker by default checked](./02-screenshot.png)

Enable **Set report location to self marker by default** so each new report drops on your own position. Saves you placing the marker by hand every time.

## Set default importance and scale

![Default Information with Importance and Event Scale](./03-screenshot.png)

Under **Default Information**, set **Importance** for the **Default Report Importance** and **Event Scale** for the **Default Report Event Scale**. New reports start with these values.

## Pick a default report template

![Report Templates with Default Report Type and overwrite option](./04-screenshot.png)

In **Report Templates**, set **Default Report Type** to the template you create most. Use **Overwrite Reports with Defaults** to customize reports made with that type.

## Set PDF export options

![Export to PDF with Automatically Open PDFs and Watermark Preferences](./05-screenshot.png)

Under **Export to PDF**, turn on **Automatically Open PDFs** to view each PDF as soon as it is created. Use **Watermark Preferences** to set the watermark to default, custom, or none.
