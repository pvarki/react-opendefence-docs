# Build a Custom Report Template

META: slides

Make your own report form so the fields match what your team actually needs to send.

## Open the Editor

![Reports Panel toolbar with the Editor button highlighted](./01-screenshot.png)

From the Reports Panel, tap **Editor**. This opens a new blank template you can build from scratch.

## Start a blank template

![Empty template showing a plus button and a three-dot menu](./02-screenshot.png)

The blank template starts with a title and a **+** button. Tap **+** to add your first field.

## Pick a field type

![Choose an Option list of field types such as Section, Text Field and Location Field](./03-screenshot.png)

Choose the field type you need from the list, for example **Section**, **Text Field**, **Location Field** or **Dropdown List(Single Selection)**.

## Add and arrange fields

![Template with a Section field and a Location Field added, each with a Required toggle](./04-screenshot.png)

Each field gets a **Field Title** and a **Required** toggle. Tap **+** again to keep adding fields until the report is complete.

## Save, export or import

![Three-dot menu showing Save Template, Export Template and Import Template options](./05-screenshot.png)

Tap the three-dot menu, then:

- **Save Template** to store it for use
- **Export Template** to share it as an XML file
- **Import Template** to load an XML template someone sent you
