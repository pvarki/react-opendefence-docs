# Report Issues & Send Feedback

META: slides

Use the User Feedback tool to report a problem with logs and screenshots attached, so it gets fixed.

## Open User Feedback

![ATAK User Feedback dialog listing feedback entries](./01-screenshot.png)

Go to **Additional Tools and Settings** > **Settings** > **Support** > **User Feedback** to open the feedback dialog.

## Start a new report

![User Feedback dialog with the plus button to add an entry](./02-screenshot.png)

In the dialog, select **+** to add an entry, then fill in the text fields. Type it, or tap the **Microphone** on the QWERTY keyboard's top row to dictate.

## Attach logs and screenshots

![Feedback entry showing attachment and edit icons](./03-screenshot.png)

To attach files like logs or screenshots, select **Attachment** > **Edit** > **+** and browse the Android file system to your file(s).

## Send the report

![User Feedback dialog with completed entries ready to send](./04-screenshot.png)

When the form is complete, select **Send**. The bug report uploads automatically to the repository as soon as you have a connection.
