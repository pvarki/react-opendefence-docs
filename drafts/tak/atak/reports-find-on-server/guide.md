# Find Reports on the Server

META: slides

Pull reports other units filed to the TAK Server, narrow them down, and save the ones you need to your own device.

## Search the server

![Reports search field with a typed query and a list of matching collection reports](./01-screenshot.png)

You need a live TAK Server connection. Select **Search**, type your text, then select **Search** again to run it. Matching reports fill the list and green icons mark their locations on the map.

## Narrow with filters

![Set Search Filters dialog with Current Map View, Date Range, Limit Shown To and Report Type options](./02-screenshot.png)

Select **Filter** to add parameters such as **Current Map View**, **Date Range**, **Limit Shown To** or **Report Type**. You can stack more than one at a time, then select **Confirm** to update the results.

## Download a report

![Map with green report markers next to an expanded report summary](./03-screenshot.png)

Select a report in the list to expand its summary and pan to it on the map. Select **Download** to the right of the entry to save a local copy. The map icon changes from green to white once it is saved.

## Edit a local report

![Local Reports panel showing each saved report with Upload, Details, PDF, Share and Delete icons](./04-screenshot.png)

Open the saved report from the Reports panel. Select **Details** (from the list or the map marker radial) to view and edit it, change the fields you need, then select **Save Draft** for a local copy or **Upload** to save and send.

## Show or hide on the map

![Local Reports panel with the Visibility eye icon on each saved report row](./05-screenshot.png)

Select the **Visibility** button to toggle whether the report shows on the map. Use it to clear clutter without deleting your local copy.
