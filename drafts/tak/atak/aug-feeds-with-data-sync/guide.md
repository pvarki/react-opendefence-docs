# Feeds with Data Sync

META: slides

## See What Feeds are Available

- Data Sync lets you read (and share) map markers and more easily.
- Feeds are like map layers: subscribe and then tick to see or disable them.
- Select Data Sync (arrows icon) on toolbar .

![](https://pvarki.getoutline.com/api/attachments.redirect?id=2c8f7afd-d4a7-4f1e-94d6-c607826302b8)

## Subscribe to RECON feed

The Deploy App TAK automatically creates a RECON feed. It is meant for fighters to receive coherent recon picture from the CP who upkeeps it.

- Select your takserver (if many)
- Select the RECON feed.

![](https://pvarki.getoutline.com/api/attachments.redirect?id=a6cdb1cd-6ae6-4d6d-a244-19c3e07b908f)

## Download & Sync

- Select **Download & Sync** to subsscribe to this feed.

![](https://pvarki.getoutline.com/api/attachments.redirect?id=e349522f-c0c9-4c79-822a-6be91c1cd981)

## Feed - Connected

- Now check that RECON feed symbol (left to the 'RECON' title of the feed) is green.
- This indicates that the subscription was successful and you receive this feed continuously.

![](https://pvarki.getoutline.com/api/attachments.redirect?id=f80514e0-bf6e-40d3-bad3-ab18ca6f6945)

## Creating, managing and subscribing feeds

- Creating, sharing and subscribing Feeds for eg. sharing a plan to a mission is easy.
- See Advanced features - **'Create & Manage Feeds'** for further information.

After successful connection to RECON feed, continue to [Blue force tracking](/doc/82c77545-7b47-4c8a-bf4b-2701a1bb3943)

## Create a Data Package

Bundle markers, shapes and routes into a Data Package so the whole team shares the same picture.

- Open **Data Package**, select **+**, then pick **Map Select**, **File Select**, **Overlays** or **Lasso** to add items.
- Tap items on the map (or browse files) to add them to the package.

![Adding map items to a new data package](./aug-01.png)

## Save the Data Package

A red asterisk on the package name means there are unsaved changes.

- Set a **Name** and any **Remarks**, then select **Done**.
- Select the **Save** icon to store the package on your device.

![Naming and saving a data package](./aug-02.png)

## Send it to Others

- Select the **Send** icon next to the package, then choose how to share it.
- Send to a **Contact** (TAK Contact), push it to the **Select Server**, hand it to another app with **Choose App**, or **Export** the file.

![Send options for a data package](./aug-03.png)

## Download a Package from the Server

- In Data Package, select the **Download** icon to list packages stored on the TAK Server.
- Pick a package from **Available Packages** to pull it onto your device.

![Available packages on the TAK Server](./aug-04.png)
