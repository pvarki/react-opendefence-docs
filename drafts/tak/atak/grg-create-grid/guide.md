# Create a Grid (GRG Builder)

META: slides

Build a gridded reference graphic (GRG) over a patch of map so everyone can call grid squares by the same letter/number.

## Open GRG Builder and start a grid

![GRG Builder toolbar in the Action Bar with the Grid icon highlighted](./01-screenshot.png)

Open the **GRG Builder** icon from the **Additional Tools** menu. The toolbar appears in the Action Bar. Pan and zoom to your area, then select the **Grid** icon.

## Set spacing and color, then place it

![GRG Builder toolbar, Grid icon selected, ready to place the grid](./02-screenshot.png)

In the **Select Grid Spacing and Color** window choose spacing, color, size and datum, then select **Done** to drop the grid. Long-press the center crosshair to move it; a short tap opens a radial with **Enter Coordinate**, **MGRS Location** or **Delete**.

## Add markers to the grid

![Toolbar with the Label icon highlighted](./03-screenshot.png)

Select the **Label** icon to drop markers on the grid. Slide the marker pallet right and left for more marker choices.

## Export the GRG

![Toolbar with the Export icon highlighted](./04-screenshot.png)

When the grid looks right, select the **Export** icon to process the imagery into a GRG (KMZ) file.

## Edit the GRG Capture

![GRG Capture edit screen showing the gridded map, info box, point list and side panel](./05-screenshot.png)

The **GRG Capture** edit screen opens. Tick a feature's check box to remove it; tap the box itself to edit it. Drag the info box or point list to re-position them on the capture.

## Adjust the grid in Edit Grid

![Edit Grid window with Label Style, Color, Spacing and Show Labels options](./06-screenshot.png)

Select **Edit Grid** to set **Label Style** (MGRS, Letter/Number or Both), grid color and spacing. Toggle **Show Labels** on or off, and **Additional Labels** to split the export across multiple image files or a multi-page PDF.

## Edit the point labels

![Edit Point List window with Text Color, Text Align and the points list](./07-screenshot.png)

Select **Point List** to open **Edit Point List**. Set **Text Color** and **Text Align** (**Left**, **Center**, **Right**), and tap a point in the list to show or hide it on the capture.
