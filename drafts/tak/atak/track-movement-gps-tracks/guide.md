# Track Movement (GPS Tracks)

META: slides

Record where you have been as a GPS breadcrumb trail, then view, recolour and share that track with your team or a TAK Server.

## Start a new track

![Track Details panel showing the current active track with title, style and export icons](./01-screenshot.png)

Open the **Track History** tool to see **Track Details** for your active track. Tap the **Add Track** icon to start a new GPS breadcrumb trail. A GPS position must be established before tracking begins.

## Name and confirm the track

![Enter New Track Name dialog with a default time-stamped name](./02-screenshot.png)

Keep the default track name or type your own, then tap **OK**. Your location is now recorded as breadcrumbs into the new track file.

## View your past tracks

![Track List panel listing saved tracks over the map](./03-screenshot.png)

Open the **Track List** to see tracks saved on the device or pulled from a TAK Server. Tap a track in the list to select it and show it on the map.

## Search for a saved track

![Track Search - Local Device dialog with callsign and a start-to-end date slider](./04-screenshot.png)

Tap the **Track Search** icon to find older tracks. Set the callsign and the **Start** and **End** time range, tick **Server Search** to include the server, then tap **Search**.

## Change the track colour

![Track Details panel with the Style colour swatch and Arrows option](./05-screenshot.png)

Select the track, then in **Track Details** tap the **Style** colour swatch to recolour it. Use **Arrows** to show direction of travel along the line.

## Export or share the track

![Track Details panel showing the export and send icons along the bottom](./06-screenshot.png)

Use the bottom icons to **Export** the track as KML, KMZ, GPX or CSV, or to **Send** it to a TAK Server. Enter a file name, tap **Next**, choose the format, then tap **Done**.
