# Add 3D Models to Map

META: slides

Drop a 3D model (like a Pix4D scan) onto the map so terrain and structures show in proper relief.

## Import the model file

![Top-down map view showing imported 3D model overlays on the terrain](./01-screenshot.png)

Open the **Import Manager**, browse to your **.OBJ** file, or a **.ZIP** that contains it, and import only that file. You can also drop the **.ZIP** into the **atak/overlays** folder to load it on startup.

## See it on the map

![Tilted 3D perspective showing the model raised above the terrain](./02-screenshot.png)

Zoom in and the model loads onto the map. Two-finger swipe up or down to tilt the view and see it raised above the surface.

## Lock the 3D view

![ATAK toolbar showing the North Arrow compass and the 3D button](./03-screenshot.png)

Long press the **North Arrow** and select **3D** to switch to 3D view. Tap **3D Lock** to hold the tilt angle while you pan the map.
