# Annotate & Style a Grid

META: slides

Once a GRG capture is built, this is where you label it, restyle it and add the markings your team needs before you share it.

## Open the GRG edit screen

![GRG Capture edit screen with the feature panel on the right](./01-screenshot.png)

After processing, the **GRG Capture** edit screen opens. The check boxes on the right turn each feature on or off; tapping a feature's name opens its editor. Drag the info box or point list to reposition them.

## Restyle the grid

![Edit Grid window with label style, color and spacing controls](./02-screenshot.png)

Tap **Edit Grid** to set **Label Style** (**MGRS**, **Letter/Number** or **Both**), grid **Color** and **Spacing**. Toggle **Show Labels** and **Additional Labels** for multi-page exports.

## Manage the point list

![Edit Point List window with text color, alignment and a list of points](./03-screenshot.png)

Tap **Point List** to set **Text Color** and **Text Align**. Use the eye icon on each point to show or hide it on the capture; the radio buttons move the list's position.

## Set the crosshair

![Edit Crosshair window with color and size sliders](./04-screenshot.png)

Tap **Crosshair** to change its **Color**, brightness and **Size**. Keep it readable against your imagery.

## Edit the info box

![Edit Info window with title, location, date and classification fields](./05-screenshot.png)

Tap **Info Box** to set **Title**, **Location**, **Date** and **Classification**, plus **Style** (**Box** or **Banner**) and **Text Align**. Each entry's text color can be set on the right.

## Add a compass

![Edit Compass window with style and color options](./06-screenshot.png)

Tick the **Compass** box to show it, then tap **Compass** to pick **Style** (**True + Mag** or **Full**) and **Color**. Use **Left** or **Right** to set its side of the grid.

## Add a scale bar

![Edit Scale Bar window with style, unit, size and segment fields](./07-screenshot.png)

Tick the scale bar box, then tap **Scale Bar** to set **Style** (**Map Range** or **Cell Range**), **Unit**, **Size** and **Segment every**. Tap **Save** on the edit screen to keep your changes.
