# Drop a CASEVAC 9-Line

META: slides

Mark a casualty on the map and send a complete 9-line / ZMIST report to HQ.

## Drop the CASEVAC marker

![CASEVAC radial menu around a medic marker on the map](./01-screenshot.png)

Open the additional tools menu, select the **CASEVAC** icon, then tap the casualty location on the map to place the marker.

## Fine-tune the location

![CASEVAC radial showing the Fine Adjust option](./02-screenshot.png)

The marker opens a radial menu. Use **Fine Adjust** to nudge the point onto the exact spot. Long press the yellow arrows for extra fine adjustment.

## Open the CASEVAC details

![CASEVAC radial showing the Details icon](./03-screenshot.png)

Select the **Details** icon on the radial to open the CASEVAC details window where you fill in the report.

## Fill the nine lines

![CASEVAC details window with the nine line-by-line fields](./04-screenshot.png)

Work down lines 1 to 9: location, callsign, **Patient by Precedence**, **Patient by Type**, enemy in area, and **Patients by Nationality**. Add free text under **Remarks**.

## Add a ZMIST report

![CASEVAC details window showing ZMIST and the Add button](./05-screenshot.png)

Next to **ZMIST**, select **Add** to attach a ZMIST report (ZAP number, Mechanism, Injury, Signs, Treatment). Tap **Add** again for more casualties; use **Delete** to remove one.

## Attach files and send

![CASEVAC details window with attachment and send controls](./06-screenshot.png)

Select the **Attachment** (paperclip) icon to add photos or files. When the report is complete, select **Send** to push the CASEVAC to your contacts.
