# Export a Grid (GRG Builder)

META: slides

Turn your built grid into a file you can share or print, then clean up the map afterwards.

## Save the grid

![Save As dialog with KMZ, PDF, JPEG and Settings (JSON) checkboxes](./01-screenshot.png)

When your edits are done, select **Save** and tick any combination of **KMZ**, **PDF**, **JPEG** or **Settings (JSON)**. **KMZ** with **Flatten map items to image** drops the grid onto the map and into Overlay Manager; **PDF** can **Append to PDF**, **Include geospatial data** or **Create multiple pages**; **JPEG** can **Create multiple images**.

## Open capture settings

![Toolbar with the Settings gear icon highlighted](./02-screenshot.png)

Select the **Settings** (gear) icon on the toolbar to configure how the GRG is captured.

## Configure the capture

![Capture Settings panel with auto-import, resolution, scaled printable map and page size](./03-screenshot.png)

Set **Auto-import GRG capture**, pick a **Resolution** (**Low** or **High**), and enable **Scaled Printable Map** to choose a **Page Size**. Select **Done** to confirm. Note: Scaled Printable Map may limit your GRG customization options.

## Delete map items

![Toolbar with the Delete trash icon highlighted](./04-screenshot.png)

To clear the map items you placed while building the GRG, select **Delete** (trash) from the toolbar.
