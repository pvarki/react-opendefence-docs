## 1. Use Geochat for Comms

TAK's Geochat provide simple textchannel communication.

## OpenDefence standard model

![Contacts list showing chat rooms such as All Chat Rooms and Groups](./aug-02.png)

Let us have **four** channels in our unit, eg. Company:

- COMMAND Channel
- BLUFOR Channel
- RECON Channel
- COMMON Channel
  Aside of them, use direct messages.

## A Channel

![Filter Contacts panel listing channels and contacts with checkboxes](./aug-03.png)

Unit-wide channel for each theme.
NO chatting in eg. platoon or company-specific channel in a company or battalion server.
**Efficiency. Avoid comms silos.**

## COMMAND Channel

- Purpose: Receive & respond to Orders
- Posting rights: Leaders
- Others: Acknowledging. Otherwise read-only. Send execution status to Blufor channel.

## Command Channel Example

Typical use:

- Unit is executing a Mission.
- Leader sends pre-planned code word "BLUE43 prepare to execute AXE" using the Command channel.
- Subordinate acknowledges.

## BLUFOR Channel

- Purpose: Send & receive status of execution
- Posting rights: Everyone

## BLUFOR Channel Example

Typical use:

- Subordinate reports, "Ready to execute AXE."
- Leader acknowledges.

## RECON Channel

- Purpose: Send & receive observations from Area of Operation
- Specifically: Always notify here if you've updated the OBSERVATION Feed.
- Posting rights: Everyone

## RECON Channel Example

Typical use:

- Subordinate reports, "Observed BOLO list car AAA-000 around GRY 4. Sent in OBS feed."
- CP recon staff acknowledges.

## COMMON Channel

- Purpose: All comms that do not fit any of the above but still need to be read by everyone.
- Posting rights: Everyone

## COMMON Channel Example

Typical use:

- Leader informs, "Gear arrived to BLUE 0 - get yours as ordered by 26JAN."
- Subordinates acknowledge.

## Using Direct Messages

![Chat tool Messages list with individual conversations](./aug-04.png)

Use direct messages for comms specific to you.
**The rule of thumb:** What is of no use to anybody but you and the recipient, should be DM'd.

## DM Example

![One-to-one GeoChat conversation with the SEND button](./aug-05.png)

- Subordinate asks, "Is BLUE 50 available? Need service to a generator."
- Command post answers, "Will relay and report answer."
