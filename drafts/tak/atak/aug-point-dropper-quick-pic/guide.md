- Quick Pic lets you take and share pictures right away.
- Select the **Camera icon** to start.

![](https://pvarki.getoutline.com/api/attachments.redirect?id=635f6145-e6c3-4b9d-9b64-d372377bb47e)

## Camera opens

## Sharing via Send

- As with Markers, the Quick Pics are only present in your device. Send to a Feed or a Role (or a user).
- Deploy App x TAK's standard model in sharing can be found at Usage by Role.

![](https://pvarki.getoutline.com/api/attachments.redirect?id=bc8fbec9-e9e4-4eb3-a27f-045552bb61aa)

## Attach a File to a Marker

![Marker detail panel with the paperclip Attachments icon and Auto Send](./aug-01.png)

- Open a marker and select the **Attachments** (paperclip) icon to add an image, video or file.
- Tick **Auto Send** to keep the marker updating to the network roughly every 60 seconds.

## Review in the Gallery

![Gallery tool listing media attachment thumbnails with file names](./aug-02.png)

- Open the **Gallery** tool to browse every media attachment with its file name and linked map item.
- Tap an image, then tap the line at the top to add a caption.
