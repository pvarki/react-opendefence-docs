# Measure Range & Bearing

META: slides

Drop a two-point line on the map to get the exact distance and azimuth between a start and an end point — the basics for fires and recon callouts.

## Drop the R&B Line

![ATAK Static R&B Line radial menu showing distance and bearing readout](./01-screenshot.png)

Open the **Range Tools** toolbar from **Additional Tools & Plugins**, then tap the **R&B Line** icon so it turns yellow. Tap your start point, then tap a second point to set the line.

## Read distance and azimuth

![A stationary R&B line on the map with a readout label showing bearing and distance](./02-screenshot.png)

The line label shows the **azimuth** and **distance** between the two points (for example, `68°M  12.21 km`). The line stays put until you delete it.

## Reposition with a Dynamic R&B Line

![ATAK Dynamic R&B Line radial menu with Pin and Lock Line options](./03-screenshot.png)

Use the **Dynamic R&B Line** instead to drag an endpoint and re-measure on the fly. When it is where you want it, tap the center of the line and use **Pin** to fix the line in place.

## Choose your bearing units

![ATAK Angle Bearing Units radial fan with degrees and mils options](./04-screenshot.png)

Tap an endpoint, then the **Angle Bearing Units** radial to switch how the azimuth is read. Pick the unit your fires net uses:

- Degrees True / Mils True
- Degrees Magnetic / Mils Magnetic
- Degrees Grid / Mils Grid
