# Draw Shapes & Graphics

META: slides

The Drawing Tools let you mark up the map with shapes, freehand sketches and
briefing graphics. Create a shape, then tap it to open its radial menu and
**Details**.

## Draw a circle or ellipse

![A drawing circle on the map with its Details panel](./01-screenshot.png)

Select the **Circle** or **Ellipse** icon, tap the centre, then tap again to set
the radius or edge. Open **Details** to set exact radius, rings, colour and line
thickness; **Label** and **Center** toggle the on-map markers.

## Draw a rectangle

![A rectangle on the map with width, length and area in Details](./02-screenshot.png)

Select the **Rectangle** icon, then tap three corners to set width, length and
depth. In **Details**, tick **Tactical Overlay** to colour-code the structure:
white is the front, black the back.

## Draw a free-form polygon or polyline

![A free-form polygon shape on the map with its Details panel](./03-screenshot.png)

Select the **Free Form** icon and tap to drop each vertex. Tap the first vertex
to close a polygon, or select **End Shape** for an open polyline. Use **Undo** to
remove the last link.

## Sketch freehand with Telestrate

![Telestration freehand contours drawn over the map](./04-screenshot.png)

Select the **Telestrate** icon to draw freehand with a finger or stylus; map
scrolling is locked while it is on. Select **Undo** to remove the last stroke, or
**End** to save the sketch as one multi-polyline.

## Place briefing graphics

![A red briefing graphic line drawn across the map](./05-screenshot.png)

Briefing graphics and tactical symbols are placed like ordinary shapes: pick the
symbol type, then draw it on the map. The chosen type is listed in the shape's
**Details** panel, where you can change or clear it.

## Add a minimum safe distance zone

![A minimum safe distance zone ring around a circle](./06-screenshot.png)

On a placed shape, select **Minimum Safe Distance** from its radial menu. Set the
**Range** and tick **Enabled** to draw a buffer zone around the shape's border.
Save it to **Favorites** with **+** to reuse it on other shapes.
