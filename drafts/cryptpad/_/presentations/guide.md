# Presentations

META: slides

CryptPad includes a Markdown-based presentation tool. You write your
presentation as text and the tool lays it out into slides.

## Start a presentation

![Creating a new Slide document](./01-create.png)

Click **+** and select **Slide**.

## Write and present slides

![Slide editor with Markdown on the left and the Present button](./02-present.png)

Write your slides as text on the left. Separate slides with `---`. Click
**Present** to enter fullscreen mode, and navigate slides with the arrow keys.

## Other file formats

CryptPad doesn't support real-time browser editing of formats such as
PowerPoint, but you can share those files on CryptDrive and edit and present them
locally.
