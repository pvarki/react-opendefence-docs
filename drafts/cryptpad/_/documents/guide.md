# Documents

META: slides

CryptPad supports creating and editing Rich Text documents in real time,
directly in your browser. Here is how to create, collaborate on, and discuss a
document.

## Create a document

![Creating a Rich Text document](./01-create.png)

Click **+** in the dashboard and select **Rich Text**. A new encrypted document
is created.

## Real-time collaboration

![Two people editing a document at once](./02-collaborate.png)

Write a document simultaneously with others — everyone sees changes as they
happen.

## Discuss the document

![Chat panel inside the document editor](./03-discuss.png)

You can also discuss the document directly inside the document editing view.

## Other file formats

CryptPad doesn't support real-time browser editing of formats such as `.docx`,
but you can share those files on CryptDrive and edit them locally.
